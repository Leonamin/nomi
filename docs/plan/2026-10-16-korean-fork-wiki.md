# 현재 fork 한국어 위키 전환

> 📎 참고 기록 · 현재 fork의 미완료 작업을 뜻하지 않습니다. 구현·검증·배포 범위는 본문과 해당 PR에서 확인합니다.


## 设计卡

| 격 | 결정 | 근거 / 검증 |
| --- | --- | --- |
| ★1 사용자 작업 | 현재 fork의 동작·개발·운영을 한국어로 찾아 읽는다. 실행 방법 찾기, 웹/데스크톱 지원 경계 확인, 과거 결정의 출처 추적을 실제 탐색 과제로 검증한다. 기존 기록과 검증 증거를 보존한다. | 사용자 승인 구조: wiki/{concepts,decisions,guides,references,logs}; 링크 검사와 내용 대조 |
| ★2 소유권 | 현재 fork 지식의 읽기 시작점은 wiki/index.md, 설정은 .agents/wiki-path 및 wiki-structure.md. 기계 계약은 기존 docs/engineering·fixes, 증거는 원래 경로를 유지한다. | docs 참조 도구 조사; 문서 생성 경로 확인 |
| ★3 재사용 | 사용자 wiki-setup의 OKF v0.1 frontmatter·디렉터리별 index.md·번호 ADR을 사용한다. 기존 문서/코드와 검증 기록을 출처로 연결하고 중복 정본을 만들지 않는다. | wiki-setup/SKILL.md; 기존 문서 생성·검사 도구 |
| ★4 문서 상태 | 현재 사실은 확인일과 소스, 결정은 승인 근거, 역사 자료는 비현행 표시, 미확인 동작은 미검증 표시. 위키 변경 로그와 과거 색인 보존. 제품 UI 상태 변경 없음. | frontmatter 및 수동 읽기 검수 |
| ★9 검증과 복구 | 위키 링크·색인·기계 참조 검사, 생성 문서 동기화 및 위험 기준 gates. Luna 내용 이관 후 조정자가 코드 대조. 기존 추적 파일/증거의 무단 삭제·바이트 변경 없음 확인. 문제 시 이 PR revert. | PR 검증 결과·이관 목록; 독립 4범주 해당 없음 |

## 범위와 보존 원칙

- 사용자 요청은 현재 fork의 한국어 위키 생성과 유효 지식 이관, 과거 기록·증거 보존, 링크·검사 도구 정합성 유지다.
- 일반 문서는 현재 사실을 추출해 위키에 통합하고 기존 문서는 출처/역사 기록으로 보존한다. 과거 파일을 최신 문서로 오인하지 않도록 진입점과 명시적 상태를 바꾼다.
- 검사 도구가 읽는 JSON 계약, 스키마, 원본 로그, 시안, 스크린샷, 영상은 경로와 바이트를 유지한다. 기존 색인은 역사 탐색에 보존한다.
- 계획·감사·조사 모든 원문을 현재 사실로 승격하지 않는다. 코드와 최근 실제 검증으로 확인된 내용만 정리한다.
- 제품 코드, 배포, 데이터, 유료 생성, upstream 정책의 실질적 변경은 범위 밖이다.
