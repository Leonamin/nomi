# PR #3 코드리뷰와 CI 회귀 수정

검토선: `/root/pr3_review`. 검토 대상은 `3ce3fbefd5039bd2fef1f8e6347743017de6e179`, 기준은 `3f5ba5e728b4123a4d18d470129ff31db0eae985`다. 이 검토선은 병합·배포와 운영 데이터 변경을 수행하지 않았다.

[실제 CI 실행](https://github.com/Leonamin/nomi-web/actions/runs/38228833325)의 Unit은 타임라인 자산 추가, 캔버스 드롭, 생성 기한 검사 세 파일을 불러오다가 실패했다. 모두 한국어 사전이 import 도중 `getDesktopBridge()`를 호출해 테스트 호스트의 초기화되지 않은 값을 읽었다. 동일한 세 파일은 변경 없는 기준 워크트리에서 33개 테스트가 통과했고, PR 원래 SHA에서는 세 파일 모두 테스트 실행 전에 실패했다. 승인된 시각 검사 예외와 별개의 실제 회귀다.

한국어 사전과 공용 리소스를 순수 데이터로 바꿨다. 웹 여부는 기존 i18n 조합 단계에서 설치된 호스트를 읽고 `resourcesForHost(isWeb)`에 전달한다. 사전을 불러오는 타임라인·캔버스·생성 경로에서 호스트를 조회하지 않는다. 기존 테스트의 mock을 바꾸거나 예외를 잡아서 숨기지 않았다. 웹 조합과 데스크톱 사전 보존 검사도 추가했다.

Contracts의 두 차단 실패는 신규 공유 언어 계약 3개 파일의 자작성 등록 누락과 승인 샘플 walk의 검출력 부족이었다. 기존 번역 엔진과 bare Node 호스트 계약을 조사한 근거를 등록했다. 샘플 walk는 English 선택 후 피드백과 도움말 제목을 실제 브라우저에서 검사한다. `concept-owners`는 원래 CI가 명시한 advisory이고, 근본 원인 계약과 Linux 시각 검사는 이 CI에서 통과했다.

확인한 결과:

- 재현된 세 실패 파일과 언어 소유자 검사: 수정 후 45개 통과. 웹 호스트 조합 검사도 포함한다.
- 전체 타입 검사 4종 통과, lint 오류 0·기존 경고 79 유지.
- i18n 6,048개 키와 보간·참조 검사 통과.
- 자작성·선행 조사·walkthrough·schema-v3 근본 원인 계약 검사 통과.
- 웹 및 Electron 빌드 통과. 실제 승인 샘플의 관계 16개와 언어 선택 피드백·도움말 제목 검사 통과.

전체 Contracts는 96개 중 94개가 통과했다. 변경 없는 기준과 동일한 macOS 시각 기준 실패 152개·통과 36개가 유일한 blocking이며, `concept-owners`는 advisory다. 기준 이미지는 변경하지 않았다.

공식 `pnpm test`의 Vitest 결과는 1,680개 파일 중 1,679개 통과, 15,981개 테스트 통과, 1개 실패다. 남은 실패는 macOS `safeStorage`의 `errSecInteractionNotAllowed(-25308)` 환경 차단으로, 변경 없는 main에서도 같은 검사 1개가 동일하게 실패했다. 키체인 설정·자격 증명·암호화 정책과 테스트를 바꾸지 않았다. 따라서 로컬 전체 검사를 통과했다고 표시하지 않는다. 후속 Linux CI의 전체 통과를 병합 조건으로 유지한다.

후속 공식 Node 검사도 모두 통과했다: worktree janitor 13개, agent-runtime 488개, 통계 8개, MCP legacy 2개, engineering system 20개. 최종 정적 근본 원인 검사와 언어 소유자 12개 검사도 통과했다. 새 SHA의 Linux CI 수신 결과는 병합 전에 별도로 확인한다. 이 보고서는 실제 GPU 생성, Electron 네이티브 UI 또는 운영 배포 완료를 증명하지 않는다.
