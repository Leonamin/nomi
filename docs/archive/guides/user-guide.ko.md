# Nomi로 첫 영상 만들기

학교 소개나 발표에 넣을 짧은 영상을 만든다고 생각해 볼게요. 처음에는 장면 하나만 만들어 보세요. 마음에 드는 결과를 얻고 나면 다음 장면을 이어 붙이면 됩니다.

이 안내는 개인용 Nomi 웹 버전 기준입니다. 웹 주소와 이미지·영상 생성에 쓰는 ComfyUI 연결은 운영자가 준비해야 합니다. 이미지나 영상을 만드는 AI를 화면에서는 **모델**이라고 부릅니다.

## 작업을 시작할 곳 만들기

프로젝트 목록에서 새 프로젝트를 만드세요. 프로젝트는 장면 설명과 이미지, 영상, 편집 내용을 모아 두는 작업 공간입니다. “학교 소개 영상”처럼 나중에 찾기 쉬운 이름을 붙이면 좋습니다.

영어 화면에서는 `New blank project`입니다. 설정의 일반 탭에서 한국어를 선택하면 메뉴와 안내를 한국어로 볼 수 있어요.

## 장면 하나 만들기

생성 화면에서 이미지 카드를 추가하세요. 카드는 장면 설명을 적고, 만들어진 결과를 확인하는 상자입니다.

만들고 싶은 장면을 적어 주세요. 예를 들면:

> 아침 햇빛이 들어오는 학교 도서관. 책상에 책과 공책이 놓여 있다. 사람은 없고, 차분한 분위기.

처음부터 긴 이야기를 다 넣을 필요는 없습니다. 장소와 눈에 보여야 할 것을 적고, 원하는 분위기를 덧붙여 보세요.

연결된 이미지 모델을 선택한 뒤 생성을 시작하세요. 사용할 모델이 없다면 운영자에게 ComfyUI 연결과 모델 등록을 확인해 달라고 요청하세요. 이 웹 버전에서는 외부 유료 API 키를 넣는 것으로 생성이 활성화되지 않습니다.

생성이 끝나면 결과를 확인하세요. 여러 결과 중 하나를 선택하는 일과, 이미 편집에 넣은 장면을 바꾸는 일은 별도입니다. 편집 중인 장면을 바꾸려면 **장면 교체**(`Replace shot`)를 사용하세요.

영상 카드는 선택한 모델이 요구하는 이미지나 다른 입력을 연결하고 움직임을 설명해 생성합니다. 모델마다 필요한 입력이 다르므로, 카드에 표시된 조건을 확인하세요.

## 순서를 정하고 재생하기

만든 이미지나 영상을 타임라인에 배치하세요. 타임라인은 장면이 재생되는 순서와 길이를 정하는 곳입니다.

장면을 원하는 순서로 옮기고, 재생해서 이어지는 모습을 보세요. 필요하면 장면의 길이를 조절하세요. 결과를 새로 생성한 뒤 현재 후보만 바꿔도 이미 배치한 장면이 저절로 교체되지는 않습니다.

## 영상 파일로 저장하기

미리보기를 확인한 뒤 MP4 내보내기를 시작하세요. 내보내기는 편집한 내용을 하나의 영상 파일로 만드는 작업입니다. 완료된 파일은 서버의 프로젝트 `exports/` 폴더에 보관됩니다. 브라우저에서는 제공되는 다운로드 기능으로 받으세요.

생성과 내보내기는 서버에서 진행됩니다. 탭을 닫았다가 다시 열면 작업 상태를 확인할 수 있습니다. 서버 자체가 재시작되면 진행 중이던 내보내기는 중단될 수 있으므로, 상태를 확인하고 다시 시작하세요.

## 막혔을 때

| 상황 | 먼저 해 볼 일 |
|---|---|
| 선택할 모델이 없어요 | 운영자에게 ComfyUI 연결과 모델 등록을 확인해 달라고 요청하세요. |
| 생성이 오래 걸려요 | 작업 상태를 확인하세요. 같은 생성을 연달아 누르기보다, 실패 표시나 결과가 나오는지 먼저 보세요. |
| 새 결과를 골랐는데 편집 화면은 그대로예요 | 현재 후보 선택과 장면 교체는 별도입니다. 배치된 장면의 `Replace shot`을 사용하세요. |
| 장면 교체가 거절돼요 | 새 영상이 편집에서 사용하는 구간보다 짧은지 확인하세요. |
| 서버에 다시 연결하라는 안내가 나와요 | 페이지를 새로고침한 뒤 작업 상태를 확인하세요. |
| AI에게 부탁해도 자동으로 영상을 만들지 않아요 | 기본은 카드를 직접 조작하는 ComfyUI 생성 방식입니다. 운영자가 서버에 외부 AI 엔진(OpenCode/Codex)을 연결했다면 도우미 패널로 카드 만들기와 생성을 맡길 수 있습니다. |

프로젝트와 파일은 웹 서버에 저장됩니다. 이 웹 버전에서 “내 컴퓨터에 저장”이라는 설명을 보면 브라우저를 쓰는 기기가 아니라 운영자가 준비한 서버의 저장 공간을 뜻하는지 확인하세요.
