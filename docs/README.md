- [과거 문서 보관 색인](archive/index.md): 계획·조사·감사·인수인계·과거 안내 원문

`research/`, `audit/`, `roadmap/`, `superpowers/` 등에 남은 짧은 안내는 기계 계약·기존 코드 참조의 주소를 보존합니다. 본문은 archive에 한 번만 보관합니다. 실행 가능한 증거 패키지·현재 규범·자동화 입력과 출력은 소유 도구의 경로에 유지합니다.

기존 문서 총목차는 [전환 전 지도](archive/2026-10-16-document-map/INDEX.md)에 보존했습니다. 과거 계획의 상태는 현재 fork의 미완료 작업 또는 운영 배포를 뜻하지 않습니다.
