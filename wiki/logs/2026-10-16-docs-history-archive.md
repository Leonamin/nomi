# docs 역사 자료의 실제 archive 이동

사용자는 위키 전환 후 docs에 남은 과거 자료도 archive로 실제 묶도록 요청했다. 계획·조사·감사·과거 안내·인수인계와 첨부 묶음을 옮기고 현재 안내는 위키로 연결한다.

기계 계약과 현재 규범·자동화 입력/출력, 실행 위치와 묶인 코드·HTML 증거는 원래 위치를 유지한다. 고정된 문서 주소에는 짧은 보관 안내만 두고 원문은 archive에서 읽는다. JSON 계약·실험 JSON·로그·이미지·영상의 내용은 바꾸지 않는다. Markdown은 원문 의미를 보존하며 링크만 새 위치에 맞춘다.
