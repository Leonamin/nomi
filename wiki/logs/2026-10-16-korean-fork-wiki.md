# 현재 fork 한국어 위키 생성

사용자가 승인한 concepts·decisions·guides·references·logs 구조를 `wiki/`에 적용했다. 기존 docs는 현재 안내, 과거 계획, 기계 계약, 검증 증거가 섞여 있었고, 웹 우선 fork의 현재 지원 범위가 상속 문서와 달랐다.

Luna 서브에이전트 세 개가 개념·결정, 사용·운영 가이드, 참고 자료를 분담했다. 현재 사실은 코드 및 최근 QA를 대조하고 출처·확인일을 명시했다. 기존 문서의 모든 주장을 일괄 현재 사실로 승격하지 않았다.

현재 문서의 진입점은 [상위 색인](../index.md)으로 통합한다. 기존 일반 안내에는 위키 진입점을 표시하고 원문을 역사 출처로 보존한다. `docs/README.md`의 과거 총목차도 삭제하지 않는다. 원인 계약, 검사 설정, 원본 로그·이미지·영상·승인 시안은 이동·변경하지 않는다.

기존 색인 검사는 `.agents/wiki-path`를 읽어 소문자 `index.md`와 각 디렉터리의 바로 아래 문서 등록을 확인하도록 확장한다. 위키를 기존 계획 상태·자동 TODO 생성 대상으로 편입하지 않는다.
