# 현재 규범과 과거 증거의 물리적 분리

사용자가 docs에는 현재 규범·기계 계약·진행 중 작업만 남기고 과거 증거·시안을 archive로 통합하도록 승인했다. 1차 정리에서 실행 문맥 때문에 유지했던 패키지도 옮기고, 실행 소비자의 파일 참조·상대 import를 함께 고친다.

이전 주소용 안내 156곳 중 현재 작업 색인 1곳은 현행 작업 목록으로 교체하고, 나머지 안내 155개는 제거한다. 구형 원인 계약은 그대로 보존하며 v3 계약의 문서·증거 참조는 실제 보관 위치를 가리킨다. 원본 실험 JSON·실행 로그·이미지·영상·HTML 내용은 유지한다. 과거 기록의 당시 상태나 실패 결과를 현재 구현·배포 사실로 바꾸지 않는다.
