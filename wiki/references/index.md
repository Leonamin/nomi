# 참고 자료

이 디렉터리는 기존 자료의 위치와 읽는 법을 안내한다. 제품의 현재 정본은 [개념](../concepts/index.md)과 [가이드](../guides/index.md)에서 찾고, 이곳은 원문을 다시 만들거나 복제하지 않는다.

- [upstream 출처와 공유 경계](upstream-and-boundaries.md): fork가 이어받은 자료와 공유·포크 경계를 추적한다.
- [외부 조사 자료 큐레이션](external-research.md): 출처·수집일·검증 시점과 조사 결과의 한계를 보존한다.
- [역사 기록과 검증 증거 찾기](history-and-evidence.md): 오래된 계획, 구현 기록, 기계 계약과 원본 증거를 구분한다.

각 문서 링크는 탐색 시작점이다. 인덱스의 누락이 알려진 경우 원본 디렉터리를 검색하고, 문서가 설명하는 상태를 현재 상태로 간주하기 전에 코드와 최근 증거를 확인한다.

- [문서 이관 지도](document-map.md): 위키로 추출한 내용과 원본을 남겨 둔 경로
