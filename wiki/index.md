# Nomi 한국어 위키

이 위키는 **개인용 웹을 우선하는 현재 Nomi fork**의 읽기 시작점이다. upstream에서 상속한 계획과 과거 실험은 현재 구현·할 일이 아니다. 제품 코드와 최신 검증 근거를 확인해 현재 안내로 추출한 내용만 여기서 갱신한다.

- [개념](concepts/index.md): 제품 범위, 웹 호스트, 제작 흐름, 생성·음성 경계와 디자인 체계
- [결정](decisions/index.md): 웹 우선 fork와 문서 정본에 관한 근거 있는 ADR
- [가이드](guides/index.md): 개발, 사용, 배포, 검증과 디자인 작업
- [참고 자료](references/index.md): upstream, 외부 조사, 역사 기록과 검증 증거
- [변경 이력](logs/index.md): 위키 구조와 지식의 변경 기록

문서의 확인일은 해당 코드·기록을 읽은 시점이다. 운영 호스트에 배포됐다는 뜻이 아니다. 실제 배포·생성·재생 검증의 유무는 각 근거에서 확인한다.
