# 사용 가이드

저장소를 실행하고 변경을 전달하는 방법과 개인용 웹 및 제작 흐름의 확인된 경계를 안내한다. 배포·제품 상태는 이 문서만으로 추정하지 말고 연결된 최신 증거를 확인한다.

- [로컬 개발과 기본 확인](local-development.md): 런타임 준비, 데스크톱·웹 개발, 관련 검사 명령
- [웹 호스트 배포 흐름](web-host-release.md): 정확한 커밋을 release로 전환하는 스크립트와 검증 경계
- [변경 전달과 검증](delivery-and-validation.md): 로컬 게이트, PR, 병합 신원, 배포 증거 구분
- [창작자 제작 흐름](creator-workflow.md): 프로젝트부터 장면 생성·편집·내보내기까지의 절차와 검증 범위
- [UI 디자인 작업](ui-design-work.md): 디자인 기준 확인, 구현 위치, 화면 검증 절차
